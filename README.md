# TranscriptCoder

The Transcriptcoder is an additional module to the Proteomic-Genomic Nexus (PG Nexus) software package. It allows users to generate a protein sequence database of isoform sequences from RNA-seq data.

## Contribution guidelines

The source codes are licensed under GPL less public licence. Users can contribute by making comments on the issues tracker, the wiki or direct contact via e-mail (see below).
